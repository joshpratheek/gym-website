# FORGE Gym Website

A premium gym website concept designed for modern fitness brands, training facilities, and performance-focused gyms.

## Overview

FORGE Gym is a fully responsive fitness website built with HTML, CSS, and JavaScript. The project focuses on delivering a bold, high-energy user experience through a dark industrial design, red neon accents, immersive imagery, and modern layouts.

The website showcases:

- Gym programs
- Membership plans
- Trainer profiles
- Member testimonials
- Facility highlights
- Contact and enquiry form
